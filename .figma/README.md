# Paku-Paku Figma workspace

Design file: [Paku-Paku — App Screens](https://www.figma.com/design/JBtJT3o2nXKsZaOscDcUNr)

File key: `JBtJT3o2nXKsZaOscDcUNr`

## What exists in the file

- Page `Components`: reusable `Button/Primary`, `Button/Secondary`, `TextField`,
  `Card`, `StatusPill` and `NavBar` components, with local color/spacing
  variables and Outfit text styles derived from `constants/theme.js`.
- Page `Screens`: editable frames for Home (`/`), Sign in (`/signin`), Menu
  (`/menu`), Cart (`/cart`), Checkout (`/checkout`), Staff order taking
  (`/staff/order`), Staff records (`/staff/records`) and Admin dashboard
  (`/admin`).

`.fig` is Figma's proprietary desktop file format and cannot be produced by
the MCP server. To add it, open the design file in the Figma desktop app and
choose **File → Save local copy…**, then place the downloaded `.fig` in this
directory.
